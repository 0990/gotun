# gotun 界面设计预览

本目录保留用户已确认的独立 HTML 设计原型。正式实现已接入 `admin/view/` 和现有接口，请通过构建后的 gotun 服务查看；构建与验证说明见 [管理后台界面](../admin-ui.md)。

- 双击 `index.html`：同时查看桌面端和手机端，也可以切换单端视图。
- 双击 `app.html`：打开完整响应式原型；可直接调整浏览器窗口宽度。
- `desktop.png` / `mobile.png`：桌面端与手机端的静态效果图。

原型无 CDN、字体或第三方资源依赖，可离线打开。宽屏使用侧栏和表格；900px 及以下改为底部导航和卡片，761–900px 使用双列卡片，手机端使用单列卡片。

## 可体验内容

- 隧道管理、智能路由出口、智能路由入口、内置服务四个页面。
- 名称、协议和地址搜索；按运行状态筛选；启用开关。
- 新建、编辑、详情、克隆和删除等界面交互；手机端弹窗从底部展开。
- 高级参数折叠、导入文件选择、检测工具、诊断和切换记录面板。

所有配置与网络指标均为示例数据，页面刷新后恢复。检测功能仅展示模拟结果，不发起网络请求；导出文件带 `preview_only` 标记，属于设计演示数据，不能作为正式 `.tun` 配置使用。

## 设计方向

浅灰绿背景、白色内容区、低饱和绿色强调色。弱化顶栏和导航，保留清晰的信息密度。手机端不用横向滚动大表格，入口、出口分行显示，运行状态、延迟和丢包率直接可见。

正式实现沿用现有 Go + Vue 2 页面与真实接口，包含加载、空态、错误、长地址和终端适配。本目录仍仅使用示例数据，作为视觉参考保留。

# 测试

为了测试方便，可在 web 界面"内置服务"中新建一个 echo 服务（监听端口设为 9999），模拟成 44.55.66.77:9999 的服务。

## 命令行测试

1. 测试 echo 服务：输入任意字符，收到相同的字符，代表 echo 服务正常运行
```bash
nc 44.55.66.77:9999
```

2. 测试转发服务：输入任意字符，会收到相同的字符，代表转发服务 OK
```bash
nc 127.0.0.1:A
```

## 更方便的测试

web 页面右上角是测试工具区，支持 httpproxy、socks5、echo 协议测试。

比如上面的 echo 服务，输入框填入 `127.0.0.1:A`，点击"echo检测"按钮，出现"tcp passed"代表成功。

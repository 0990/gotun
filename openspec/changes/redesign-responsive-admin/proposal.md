## 原因

管理后台固定侧栏和宽表格挤占手机屏幕，列表和表单无法正常操作。用户已确认 `docs/ui-preview/` 中的浅色响应式原型，并授权开始正式实现。

## 变更内容

- 统一为白色内容区、浅灰背景与绿色强调色，桌面使用侧栏，手机使用底部导航；按用户确认的方案 02 加深主要文字和辅助说明，放大地址并加粗表头。
- 隧道、智能路由入口/出口及内置服务使用宽屏表格、窄屏卡片；增加当前列表搜索和状态筛选。
- 将隧道操作放到每条记录，重排新建与编辑表单，统一弹窗和检测工具布局。
- 保留现有 API、配置格式、认证、探测、带宽测试、MTR、导入导出及路由优先级语义。

## 能力

### 新增能力

- `responsive-admin`：管理后台的响应式导航、列表、表单与反馈。

### 修改能力

无；现有智能路由转发规则保持不变。

## 影响

影响 `admin/view/`、`admin/resource/dist/` 中的界面和共享资源；继续使用 Vue 2、http-vue-loader 与现有组件库，无需引入前端构建工具。静态资源由 Go embed 打包，需要重新编译二进制。

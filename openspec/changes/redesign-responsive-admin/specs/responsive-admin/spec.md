## Purpose

为隧道、智能路由和内置服务提供统一的响应式管理体验，使用户在桌面和手机上均可阅读连接状态、编辑配置并执行诊断，同时保持现有接口与配置兼容。

## ADDED Requirements

### Requirement: 清晰的文字层级
管理后台 MUST 使用深灰色展示名称、地址和辅助说明，并仅在按钮、开关及状态等位置使用绿色强调；桌面地址字号不得小于 14px，手机地址字号不得小于 13px，表头必须加粗。

#### Scenario: 查看连接地址
- **WHEN** 用户在桌面或手机查看隧道列表
- **THEN** 名称、地址、协议和辅助说明使用清晰的深色文字，手机入口与出口标签保持完整显示

### Requirement: 响应式导航与列表
管理后台 MUST 在宽屏显示侧栏和表格，在 900px 及以下显示底部导航和卡片；320px 手机宽度不得出现整页横向溢出。

#### Scenario: 手机访问
- **WHEN** 用户在 390px 宽度打开四个管理列表之一
- **THEN** 列表占据可用宽度，底部导航可切换四个页面，每条记录可直接编辑和启停

### Requirement: 搜索筛选与真实状态
管理后台 MUST 支持当前已加载列表的名称、地址和协议搜索与状态筛选，并明确展示加载、空列表和错误状态；禁用、运行失败和健康未知不得被显示为健康运行。

#### Scenario: 组合筛选
- **WHEN** 用户输入关键词并选择已停用
- **THEN** 仅显示当前列表中同时满足两项条件的记录，界面标明搜索范围

### Requirement: 配置和诊断兼容
管理后台 MUST 保留现有配置字段、成员顺序、导入导出、健康探测、带宽测速及 MTR 功能，并使表单与弹窗适配手机。

#### Scenario: 手机编辑配置
- **WHEN** 用户在手机上编辑并保存隧道或路由
- **THEN** 所有原有配置字段可访问，保存调用现有接口，失败时保持表单可继续编辑

#### Scenario: 检测与终端
- **WHEN** 用户打开检测工具或 MTR
- **THEN** 实际检测继续使用现有接口，终端和输出在容器内展示，关闭或离开页面继续正确释放会话
